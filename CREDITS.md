# Grow With Friends: credits

Made by apl0ng. Written with Claude Code (Anthropic) as the coding agents: a lead session and the sub-developers of
each milestone, working from the plans in RELEASE.md and PLAN.md.

## Made for this game
Everything the player sees and hears, apart from the engine and the font below, was made for this game and is in this
repository.

- **Code:** the game is GDScript (`scripts/`, `scenes/`), multiplayer included: ENet through Godot's high-level
  multiplayer, voice chat with our own capture, mu-law codec and relay (`scripts/core/voice.gd`).
- **Sound:** 78 sounds, every one synthesised from a recipe in code when the game starts (`scripts/art/sfx.gd`:
  oscillators, noise and envelopes into 16-bit WAV in memory). No recordings, no sample packs, no music. The voices
  are the players'.
- **Models:** 83 models in `art/models/`, each built by a Python script driving Blender (`tools/blender/models/`,
  43 families, with the helper library `tools/blender/gwf.py`; MODELING.md has the pipeline). Nothing was modelled by
  hand or bought.
- **Materials and look:** the toon material library in `art/materials/` and the theme in `art/ui/theme.tres` are
  generated by `tools/gen_placeholder_art.gd` and `tools/gen_factory_art.gd`; at runtime `scripts/art/toonify.gd`
  shades the models. No bitmap textures. The faces are built in code (`art/props/face.tscn`, `scripts/art/toon_face.gd`).
- **Shaders:** `art/shaders/toon.gdshader` (a cel-band toon shader) and the spore fog overlay in
  `scripts/core/spores.gd` (a canvas_item shader written inline).
- **Icon:** `icon.svg`, drawn for this game.

## Not made for this game
- **Godot Engine 4.7.2**, which runs the game and is compiled into `GrowWithFriends.exe`. MIT licence (the engine
  reports it as "Expat"). Copyright (c) 2014-present Godot Engine contributors; (c) 2007-2014 Juan Linietsky, Ariel
  Manzur. The engine carries third-party components with their own licences (FreeType, HarfBuzz, ENet, Mbed TLS,
  zlib, libpng and the rest); the full list with every notice is built into the engine (`Engine.get_copyright_info()`,
  `Engine.get_license_info()`, `Engine.get_license_text()`).
- **The font: Open Sans SemiBold**, Godot's built-in default font. The theme (`art/ui/theme.tres`) sets no font file:
  its two FontVariations ("body_bold", emboldened 0.45, and "chunky", 0.9) sit on the engine's default, and the 3D
  labels and signs use the same font (`ThemeDB.fallback_font`, which reports "Open Sans SemiBold"). Copyright 2020 The
  Open Sans Project Authors. SIL Open Font License 1.1. It ships inside the engine binary, not as a file of ours.
- **Blender** builds the models from the scripts; nothing of Blender ships with the game.
